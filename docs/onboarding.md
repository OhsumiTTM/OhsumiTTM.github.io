# 新しい団体の立ち上げ(テンプレート版)

Ohsumi は、各団体の Google アカウントにスプレッドシートと Google Apps Script(GAS)を置いて動きます。
FSIF が用意したテンプレートを「コピーを作成」するだけで、コードの貼り付けは要りません。

所要時間の目安: **20〜30分**(Google アカウントの用意を除く)

---

## 0. FSIF が行うこと(団体ごと)

1. レジストリの管理画面(`<サイトの URL>/registry-admin/`)の「登録コード」で、**新しい団体の登録コード**を発行します
   (団体名・担当者の名前とメールアドレス)。コードは発行した画面で1回だけ表示されます。有効期限は14日・1回限りです
2. 団体の担当者に、次の4つを渡します。**登録コードは、ほかとは別の連絡手段で**渡してください
   - テンプレートの「コピーを作成」のリンク(`…/copy` で終わるもの)
   - 登録コード
   - レジストリの URL(スクリプトプロパティ `REGISTRY_URL` に入れる値)
   - ログインのクライアント ID(スクリプトプロパティ `GOOGLE_OAUTH_CLIENT_ID` に入れる値)

---

## 1. Google アカウントを用意する(団体の担当者)

- 団体の運用に使う Google アカウントを用意します。スプレッドシートと GAS は、このアカウントが持ち主になります
- **大学のアカウントなど、卒業や異動で消えるアカウントは使わないでください。** 消えると団体のデータごと使えなくなります
- 30人以上の団体は、メールの1日の上限が大きい Google Workspace のアカウントをおすすめします
- **2段階認証を有効に**し、バックアップコードを団体で決めた場所に保管してください

## 2. テンプレートをコピーする

1. 上で用意したアカウントでログインした状態で、FSIF から受け取った「コピーを作成」のリンクを開きます
2. 「コピーを作成」を押します。名前は団体名などに変えて構いません

> スクリプトの設定(団体ID・ログインの鍵など)はコピーされません。団体ごとに次の手順で新しく作られます。

## 3. 初期設定を実行する

1. コピーしたスプレッドシートで「拡張機能」→「Apps Script」を開きます
2. 上部の関数の一覧で **`setupOhsumi`** を選び、「実行」を押します
3. 「承認が必要です」と出たら、「権限を確認」→ 自分のアカウントを選ぶ →「詳細」→「(安全ではないページ)に移動」→「許可」の順に進みます
   - 「Google がこのアプリを確認していません」と出るのは、団体自身のスクリプトのためです。そのまま進めて問題ありません
4. 実行ログに完了のメッセージが出れば成功です(シート・団体ID・ログインの鍵・定期の処理が作られます)

## 4. ウェブアプリとしてデプロイする

1. Apps Script の右上の「デプロイ」→「新しいデプロイ」を押します
2. 「種類の選択」の歯車から「ウェブアプリ」を選びます
3. 次のように設定します
   - 説明: `Ohsumi`(何でも構いません)
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」を押します(承認を求められたら、手順3と同じように許可します)
5. 表示された **ウェブアプリの URL**(`https://script.google.com/macros/s/…/exec`)をコピーして控えます
   - ブラウザのアドレスバーではなく、**この画面に出た URL** を使ってください(`/u/1/` などを含む形は使えません)

> 今後コードを更新する時は、「新しいデプロイ」ではなく「デプロイを管理」→ 鉛筆のアイコン →「新バージョン」で更新します。新しいデプロイを作ると URL が変わります。

## 5. スクリプト プロパティを入れる

Apps Script の左の歯車「プロジェクトの設定」→ 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」で、次の3つを入れて保存します。

| プロパティ | 値 |
|---|---|
| `REGISTRY_URL` | FSIF から受け取ったレジストリの URL |
| `GOOGLE_OAUTH_CLIENT_ID` | FSIF から受け取ったクライアント ID |
| `OHSUMI_WEBAPP_URL` | 手順4で控えたウェブアプリの URL |

すでに入っているほかのプロパティ(`ORG_ID` など)は**変えないでください**。

## 6. レジストリに登録する

1. スプレッドシートのタブに戻り、**ページを再読み込み**します。上部に「Ohsumi」メニューが出ます
2. 「Ohsumi」→「レジストリに登録する…」を選びます
3. ダイアログに出る接続先の URL が、手順4で控えた URL と同じか確かめます
4. FSIF から受け取った**登録コード**を入れて「OK」を押します(初回は権限の確認が出ます。手順3と同じように許可します)
5. 「登録しました」のダイアログに、**団体ID** と **初期設定コード** が1回だけ出ます。控えてください
   - 初期設定コードは、最初の代表になる人に伝えます(有効期限は72時間・1回限り)
   - 控え損ねた・期限が切れた時は「Ohsumi」→「初期設定コードを作り直す」で作り直せます
   - 「応答を受け取れませんでした」と出た時は、少し待ってから**同じ登録コードで**もう一度行ってください(24時間以内なら二重には登録されません)

## 7. 最初の代表が入る

1. 招待リンク `<サイトの URL>/?org=<団体ID>` を開きます
2. ログイン画面で「初期設定コードをお持ちの方」を押し、初期設定コードを入れます
3. 「Google でログイン」を押し、**代表になる人の個人の Google アカウント**でログインします。代表として登録され、そのまま入れます

以降のメンバーは、代表が管理画面の「Members」で追加します(「招待メールを送る」で招待リンクが届きます)。

---

## 立ち上げた後に守ること

- **スプレッドシートを、ほかの人と共有しないでください。** 共有すると、画面の権限に関係なく、全員のデータが見えてしまいます。代表に「閲覧者」として共有するのだけは構いません
- スプレッドシートを直接編集しないでください。必要な時は、作業の前に FSIF に相談してください
- 団体のアカウントのパスワードと2段階認証は、代替わりの時に必ず引き継いでください

## 困った時

| 症状 | 確かめること |
|---|---|
| 「Ohsumi」メニューが出ない | ページを再読み込みしたか。手順3を実行したか |
| 登録で「接続先の URL が正しくありません」 | `OHSUMI_WEBAPP_URL` が手順4の画面の URL(`…/exec`)そのままか |
| ログインで「登録されていません」 | 招待リンクの団体が正しいか。代表に、そのメールアドレスの登録を頼む |
| 読み込みに失敗する | ブラウザを操作する AI の拡張機能を止めて試す |

それでも解決しない時は、管理画面の「診断情報」を送り、受付番号を添えて FSIF に問い合わせてください。

## FSIF 向け: テンプレートの作り方と更新

### 作り方(最初の1回)

1. FSIF の運用アカウントで、新しいスプレッドシート「Ohsumi テンプレート」を作ります
2. 「拡張機能」→「Apps Script」を開き、`gas/Code.gs` の中身を貼り付けて保存します
3. 「プロジェクトの設定」で「『appsscript.json』マニフェスト ファイルをエディタで表示する」をオンにし、`gas/appsscript.json` の中身で置き換えて保存します
4. **テンプレートでは `setupOhsumi` を実行しないでください。** FSIF のアカウントに定期の処理が作られてしまいます
5. スクリプト プロパティには何も入れません
6. 最初のシートの名前を「はじめに」にし、このファイルの手順1〜7を短く書いておきます
7. 共有を「リンクを知っている全員」が「閲覧者」にします
8. 共有のリンクの末尾の `/edit…` を `/copy` に置き換えたものを、「コピーを作成」のリンクとして使います

### 更新(Code.gs を変えた時)

- テンプレートの Apps Script の `Code.gs`(と `appsscript.json`)も、同じ内容に貼り替えて保存します
- テンプレートには `SampleData.gs` を足しません(団体に配るのは `Code.gs` だけです)

### サンプル・デモの団体(SampleData.gs)

- サンプル(テスト環境)とデモの団体だけ、`Code.gs` に加えて `gas/SampleData.gs` を Apps Script に足します(「ファイル」の ＋ →「スクリプト」で `SampleData` という名前のファイルを作って貼る)。
  サイトの `/gas/` には置いていないので、リポジトリの `gas/SampleData.gs` から貼ります
- デモの団体は、スクリプトプロパティ `DEMO_ORG` を `true` にしてから `seedShowcaseData` を実行します(見本データ。消す時は `deleteShowcaseData`)。
  サンプルの団体は `TEST_ENVIRONMENT` を `true` にして、`seedSampleData`(崩れ確認用)・`seedShowcaseData` のどちらも使えます
- **更新の時は、`Code.gs` と `SampleData.gs` を両方貼り替えます。** 版が組になっていないと、`SampleData.gs` の関数は実行の最初に止まります
- 詳しくは gas/README.md の「11.5.」
- 既に立ち上げた団体には影響しません(各団体のコピーは、それぞれ別に更新します)
