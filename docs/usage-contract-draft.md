# Ohsumi 利用契約書(案)

> サービス紹介資料と食い違う時は、この文書(と利用規約・プライバシーポリシー)を優先します。

未来宇宙産業フォーラム(以下「FSIF」)と、〔団体名〕(以下「利用組織」)は、組織運営支援サービス「Ohsumi」(以下「本サービス」)の利用について、次のとおり契約(以下「本契約」)を締結します。

## 第1条(目的)

本契約は、FSIFが利用組織に本サービスを提供する条件と、利用組織がFSIFに行うアンケートへの回答およびデータ提供について定めます。

## 第2条(定義)

本契約の用語は、本契約に定めるもののほか、Ohsumi 利用規約(以下「利用規約」)の定めによります。

1. 「アンケート」とは、FSIFが利用組織に回答を依頼する、定性的なデータを得るための調査をいいます。
2. 「データ提供」とは、利用組織が、団体単位の集計値をFSIFに提供することをいいます。
3. 「機能停止」とは、本サービスを読み取り専用にすることをいいます。
4. 「提供停止」とは、本サービスを利用できない状態にすることをいいます。
5. 「レジストリ」とは、FSIFが運用する、利用組織の識別子・接続先・機能停止と提供停止の状態を管理する仕組みをいいます。

## 第3条(プラン)

利用組織は、次のいずれかのプランを選び、申込書に記載します。

| | Cosmo Baseプラン | Ohsumiプラン | 有償プラン |
| --- | --- | --- | --- |
| 料金 | 無償(有償プランと同等の機能) | 無償 | 有償(第4条) |
| アンケートの目安 | 年6回 | 月1回 | 年2回 |
| アンケートの上限 | 年12件 | 年24件 | 年4件 |
| データ提供 | 努力義務 | 必須 | 完全任意 |
| アンケートに回答が無い時 | 機能停止 | 機能停止 | サポートの停止のみ |

## 第4条(料金)

1. Cosmo Baseプランと Ohsumiプランは、無償とします。
2. 有償プランの料金は、利用者の人数(本サービスにメンバーとして登録した人数)に応じて、次のとおりとします。

   | 利用者の人数 | 料金(月額) |
   | --- | --- |
   | 10人以下 | 10,000円 |
   | 11〜100人 | 75,000円 |
   | 101人以上 | 個別にご相談 |

3. 101人以上の料金は、FSIFと利用組織が協議して定め、申込書に記載します。
4. 有償プランの契約は、一般社団法人の設立後に開始します。それまでの間、FSIFは有償プランの申込みを受け付けません。
5. 有償プランの支払方法および支払期日は、【未定】とします。

## 第5条(アンケート)

1. アンケートの目的は、定性的なデータを得ることです。利用組織は、団体として1件の回答をします。
2. FSIFは、1回あたり10分以内で回答が終わる内容とします。
3. FSIFがプランの上限を超えてアンケートを依頼する場合は、利用組織の別途の許可を得ます。上限を超える分について、FSIFは回答を強制できません。
4. 回答の期限は、送付の日から2週間とします。
5. FSIFは、回答が確認できない時、送付から7日目・10日目・14日目(期限の日)に、回答をお願いするお知らせ(リマインド)を送ります。期限の後は、15日目・21日目・26日目・27日目に送ります。
6. 期限までに回答が無い時は、期限の日に、「回答が無ければ14日後に機能を停止する」ことを予告します。

## 第6条(アンケートに回答が無い時)

1. Cosmo Baseプランと Ohsumiプランでは、前条第6項の予告の後も回答が無い時、FSIFは送付から28日目に、その利用組織の本サービスを機能停止にします。
2. 機能停止中も、登録データの閲覧と書き出しはできます。作成と編集はできません。登録データは消去しません。
3. FSIFは、回答を確認したら、すぐに機能停止を解除します。
4. 有償プランでは、回答が無い時も機能停止にしません。FSIFは、回答を確認するまで、本サービスのサポート(問い合わせへの対応など)を停止することがあります。

## 第7条(データ提供)

1. データ提供の目的は、定量的なデータを得ることです。
2. 提供するデータは、団体単位の集計値(人数、タスク数、ログイン回数など)とします。個人を特定できる形のデータは含めません。
3. データ提供の扱いは、プランにより次のとおりとします。
   - Cosmo Baseプラン:利用組織は、データ提供に努めるものとします(努力義務)。
   - Ohsumiプラン:利用組織は、データ提供を行うものとします(必須)。
   - 有償プラン:データ提供は、利用組織が任意に行うものとします(完全任意)。
4. データ提供の方法は、利用組織のプログラムから自動で送る仕組みをFSIFが用意するまでの間、【未定】とします。

## 第8条(アンケートの回答と集計値の使い道)

1. FSIFは、アンケートの回答とデータ提供の集計値を、本サービスの機能の改善と、将来の事業化およびその実績としての活用のために使用します。
2. FSIFは、個人を特定できる形では、原則として使用しません。
3. FSIFは、利用組織の名称を示して使用する場合、事前にその利用組織の確認を取ります。
4. 利用組織を特定できない形であれば、FSIFは、利用組織の許可なく、資料などに使用できます。
5. ただし、利用組織の数が少ないうちは、名称を伏せても数字から利用組織を特定できることがあるため、FSIFは、3団体以上をまとめた数字でない場合は、事前にその利用組織の確認を取ります。

## 第9条(登録データの保存と管理)

1. 登録データは、利用組織が所有するGoogleアカウント上のスプレッドシートに保存し、利用組織が管理します。FSIFは登録データにアクセスせず、保存もしません。
2. FSIFが利用組織から受け取るのは、第5条のアンケートの回答、第7条の集計値、および本サービスの提供に必要な利用組織の情報(レジストリの情報を含む)だけです。これらの取扱いは、プライバシーポリシーによります。

## 第10条(提供停止)

1. FSIFは、本契約の終了、利用組織による本契約または利用規約への違反その他これらに準ずる場合、その利用組織への本サービスを提供停止にできます。
2. FSIFは、提供停止の14日前までに、利用組織に予告します。ただし、緊急の場合は、当日の予告で提供停止にできます。
3. 提供停止中は、利用組織は本サービスを利用できません。この場合も、登録データは利用組織のGoogleアカウント上のスプレッドシートに残ります。
4. 利用組織のプログラムがレジストリに状態を確かめられない場合も、利用組織は本サービスを使い続けることができます。

## 第11条(契約期間と終了)

1. 本契約は、締結の日から効力を生じます。
2. Cosmo Baseプランと Ohsumiプランは、契約期間を定めません。
   - 利用組織は、いつでもFSIFに知らせて、本契約を解約できます。
   - FSIFが本契約を終了する場合は、終了の日の30日前までに利用組織に知らせます。
3. 有償プランは、1か月ごとに自動で更新します。
   - 利用組織が解約する場合は、更新する月の前月の末日までにFSIFに知らせます。この場合、本契約は、その前月の末日に終了します。
4. 本契約が終了した後の本サービスは、第10条のとおり提供停止にします。登録データは、利用組織のGoogleアカウント上のスプレッドシートに残ります。

## 第12条(利用規約との関係)

本契約に定めのない事項は、利用規約およびプライバシーポリシーの定めによります。本契約と利用規約の定めが異なる場合は、本契約の定めを優先します。

## 第13条(準拠法・管轄)

本契約は日本法に準拠します。本契約に関して紛争が生じた場合、横浜地方裁判所を第一審の専属的合意管轄裁判所とします。
