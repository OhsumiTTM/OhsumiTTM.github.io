# リリースのチェックリスト(Go/No-Go。下書き)

10/10 の公開の判定に使います。**「止める」の項目が1つでも満たせなければ No-Go**、「確かめる」は満たせなくても理由と対応を書けば Go にできます。
担当・確認日・結果の欄は、判定の会議で埋めます。

## 1. 品質

| # | 項目 | 区分 | 確かめ方 |
|---|---|---|---|
| Q1 | main の CI がすべて通っている(型・テスト・ビルド・check:layout・画面の通しテスト) | 止める | GitHub の Actions |
| Q2 | 公開する版のすべての PR がマージ済みで、下書きの PR が残っていない | 止める | PR の一覧 |
| Q3 | API・画面の通しテストが通っている(`pnpm test`・`pnpm test:e2e`) | 止める | docs/release-e2e.md の 1・2 |
| Q4 | 本番の Google のログインで、手の確かめ(招待 → 代表 → メンバー → タスク → ログアウト)が通る | 止める | docs/release-e2e.md の 3 |
| Q5 | スマホ(iPhone・Android)の実機で、ログイン・タスクの作成・完了ができる | 止める | 実機 |
| Q6 | 本番のビルドにデモのログインが含まれていない | 止める | `pnpm build` の最後の確認 |
| Q7 | 既知の不具合の一覧があり、公開を止める不具合が無い | 確かめる | Issue の一覧 |

## 2. セキュリティ・個人情報

| # | 項目 | 区分 | 確かめ方 |
|---|---|---|---|
| S1 | リポジトリ・README・docs に秘密の値(鍵・Webhook・パスワード)が無い | 止める | secret scanning・目視 |
| S2 | スプレッドシート・アップロードのフォルダが「制限付き」で、GAS のアカウント以外が編集できない | 止める | 代表の管理画面の共有の警告が無い |
| S3 | CSP がビルドに入っている | 止める | ビルドの「CSP を入れました」 |
| S4 | レジストリの管理者の許可リスト(`ADMIN_EMAILS`)が、決めた人だけ | 止める | レジストリのスクリプトプロパティ |
| S5 | 団体の GAS の版が最新で、「更新が要る」団体が無い | 止める | レジストリの管理画面 |
| S6 | 個人情報の削除(退会)の保存期間が、プライバシーポリシーと一致している | 確かめる | 代表の管理画面・ポリシー |
| S7 | 診断情報・集計値に個人情報が入っていない | 確かめる | テスト・プレビュー |

## 5. 法務・表記

| # | 項目 | 区分 | 確かめ方 |
|---|---|---|---|

| # | 項目 | 区分 | 確かめ方 |
|---|---|---|---|
| B1 | 画面の色・ロゴ・アイコンがブランドガイドライン v0.4 どおり | 確かめる | docs/brand.md・check:layout のロゴの確かめ |

## 7. 判定

- **Go:** 「止める」の項目がすべて満たされ、「確かめる」の項目で満たせないものは、理由と対応の期限が書かれている。
- **No-Go:** 「止める」の項目に満たせないものがある。公開の日を動かすか、項目の扱いを判定の会議で決め直す。
- 判定の記録(日時・参加者・結果・残した項目)を残す。
