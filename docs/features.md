# 機能一覧(10/10 公開の時点)

- **リリース機能一覧:** 公開の時点で、画面とコードで確かめられる機能です。「一部」は、できる範囲を注記に書きました。
- **未実装・将来機能一覧:** 「開発予定」(時期を決めて作るもの)と「将来構想」(方向だけ決めたもの)に分けました。
- 紹介資料の「実装済み」と書く範囲は、この一覧の「実装済み」に合わせてください。

## 1. リリース機能一覧(実装済み)

### 組織・管理

|---|---|

| 役職ごとの「できる操作」 | メンバーの登録・招待、役職の変更、退会、報告先などの人事の項目、研修の承認、採用、プロジェクトの削除、タスクのゴミ箱、団体のルール、団体のロゴを、役職ごとに許可できる(決められるのは代表だけ)。既定は今までと同じ(代表: すべて、制限なしの管理者: 団体のルールとゴミ箱)。画面には、その人ができる操作だけを出す |
| 昇権の防止 | 役職を変えられる人も、最上位の役職・自分の持っていない操作ができる役職は付けられず、自分・最上位の人の役職は変えられない(GAS が確かめる) |

| メンバーの登録・招待のメール・参加状況(長く入っていない人の知らせ・活動休止) | |
| 退会・担当の解除・個人情報の削除(保存期間の設定) | 退会は「できる操作」で役職ごとに許可。個人情報の削除は代表だけ |
| 経費申請(領収書・多段の承認)・フォーム | |
| 日報・週報 | |
| 採用管理(候補者) | |

| 団体のスプレッドシート・Apps Script を開く | 最上位の役職の人だけ。GAS の更新の知らせと、団体設定の「GAS とスプレッドシート」から(団体のアカウントでログインしたブラウザで開く) |

| ADMIN の画面の構成 | 状況・仕事・人と組織・育成・申請と記録・設定のグループに分け、役職ごとに見られるタブを選べる |
| バックアップ(毎日)と戻す操作(全体・一部のタスク) | 代表だけ(役職の「できる操作」でも渡せない) |
| 毎日・毎時の処理の見張り・共有の確かめ・長くなった記録の知らせ | |

| 自分のページの概要 | 自分のページも、ほかの人のページと同じく「概要」のタブが最初で、開くと概要を出す(活動実績など)。個人の設定はタブではなく「個人設定」の画面にある |
