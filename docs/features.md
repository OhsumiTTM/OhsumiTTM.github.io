# 機能一覧(10/10 公開の時点)

- **リリース機能一覧:** 公開の時点で、画面とコードで確かめられる機能です。「一部」は、できる範囲を注記に書きました。
- **未実装・将来機能一覧:** 「開発予定」(時期を決めて作るもの)と「将来構想」(方向だけ決めたもの)に分けました。
- 紹介資料の「実装済み」と書く範囲は、この一覧の「実装済み」に合わせてください(docs/release-checklist.md の L3)。

### 組織・管理

## 2. 未実装・将来機能一覧

### 2.1. 実装済み(一部)— 資料では書き方をそろえるもの
| 機能 | できること | 足りないこと |
|---|---|---|
| Ohsumi 共通のスキルの基準 | 共通のスキルの一覧、実績のファイルでの持ち出し | 団体をまたいだ自動の引き継ぎ |
| 承認履歴 | タスクごとの変更の記録・経費の履歴 | まとめて見る画面 |
| ナレッジ | 横断の検索・振り返り・学習コンテンツ | 手順書・Wiki のようなページ |
| カレンダー | 一覧の表示・Google カレンダーへの追加 | Google カレンダーの予定の表示 |

### 2.2. 開発予定
