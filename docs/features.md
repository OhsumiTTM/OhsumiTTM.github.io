## 2. 未実装・将来機能一覧

### 2.1. 実装済み(一部)— 資料では書き方をそろえるもの
| 機能 | できること | 足りないこと |
|---|---|---|
| Ohsumi 共通のスキルの基準 | 共通のスキルの一覧、実績のファイルでの持ち出し | 団体をまたいだ自動の引き継ぎ |
| 承認履歴 | タスクごとの変更の記録・経費の履歴 | まとめて見る画面 |
| ナレッジ | 横断の検索・振り返り・学習コンテンツ | 手順書・Wiki のようなページ |
| カレンダー | 一覧の表示・Google カレンダーへの追加 | Google カレンダーの予定の表示 |

### 2.2. 開発予定
| 機能 | 時期の目安 | 主な作業 | GAS の変更 |
|---|---|---|---|
| チャンネル配信(更新を段階的に届ける) | v1.1 | レジストリのチャンネル・画面の版の出し分け | 少し |
| テンプレートの「コピーを作成」での立ち上げ | v1.1 | テンプレート・初期設定のメニュー・手順書 | 要る(コピーの実験の結果による) |
| 団体独自のスキルの基準(段階ごとのポイント・認定の条件) | v1.1〜1.2 | 設定の画面・レベルの計算 | 要る |
| 組織内評価をスキルの根拠にする | v1.2 | 評価の入力・ポイントへの反映 | 要る |
| 項目ごとの公開範囲の設定(本人・上長・部門長・幹部) | v1.2 | 設定の画面・GAS の読み取りの決まり | 要る(安全に関わる) |
| アサインの候補の区別(即戦力・成長・支援・メンター) | v1.1 | おすすめの計算と表示 | 要らない(画面だけ) |
| 承認履歴の画面 | v1.1 | 画面 | 要らない見込み |
| アンケートの回答の自動の確認(Google フォームの回答) | v1.2 | レジストリ | 団体の GAS は要らない |
| 停止の2人目の承認 | v1.2 | レジストリ | 団体の GAS は要らない |
| コメント・1on1・変更の記録を別のシートに移す(1つの記録の5万文字の上限への対策) | 記録が上限に近づく前 | データの持ち方の移行 | 要る(大きい) |
| 暗い表示 | 未定 | 画面(ロゴの案は docs/brand.md) | 要らない |

### 2.3. 将来構想
