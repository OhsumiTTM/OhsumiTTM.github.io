# Ohsumi 利用規約

制定日:2026年9月28日  
改定日:2026年10月1日

この利用規約(以下「本規約」)は、未来宇宙産業フォーラム(以下「FSIF」)が提供する組織運営支援サービス「Ohsumi」(以下「本サービス」)を利用する方に適用されます。本サービスにログインした時点で、本規約に同意したものとみなします。

## 第1条(定義)

1. 「利用組織」とは、FSIFと本サービスの利用契約を締結した団体をいいます。
2. 「利用者」とは、利用組織によってメンバーとして登録され、本サービスを利用する方をいいます。
3. 「登録データ」とは、利用者または利用組織が本サービスに入力・登録した情報をいいます。
4. 「プラン」とは、利用契約で定める本サービスの利用の区分(Cosmo Baseプラン、Ohsumiプラン、有償プラン)をいいます。
5. 「アンケート」とは、FSIFが利用組織に回答を依頼する、定性的なデータを得るための調査をいいます。
6. 「データ提供」とは、利用組織が、団体単位の集計値(人数、タスク数、ログイン回数など)をFSIFに提供することをいいます。
7. 「機能停止」とは、本サービスを読み取り専用にすることをいいます。機能停止中も、登録データの閲覧と書き出しはできますが、作成と編集はできません。
8. 「提供停止」とは、本サービスを利用できない状態にすることをいいます。

## 第2条(本規約と利用契約の関係)

FSIFと利用組織の間の権利義務(プラン、料金、アンケートへの回答、データ提供、機能停止、提供停止など)は、別途締結する利用契約によります。本規約は、利用者が本サービスを利用する際のルールを定めるものです。

## 第3条(プランと料金)

1. Cosmo BaseプランとOhsumiプランは、無償です。
2. 有償プランの料金は、利用者の人数に応じて、次の表のとおりです。
3. 有償プランの契約は、一般社団法人の設立後に開始します。それまでの間は、有償プランの申込みを受け付けません。
4. 料金の支払方法その他の条件は、利用契約で定めます。

| 利用者の人数 | 有償プランの料金(月額) |
| --- | --- |
| 10人以下 | 10,000円 |
| 11〜100人 | 75,000円 |
| 101人以上 | 個別にご相談 |

## 第4条(利用)

1. 利用者は、利用組織が登録したGoogleアカウントでログインして本サービスを利用します。
2. 利用者は、自らのGoogleアカウントと端末を適切に管理するものとします。共用の端末では、ログイン情報を保存しない設定で利用し、利用後はログアウトしてください。
3. 利用者が利用組織を退会した場合など、利用組織が登録を削除した時点で、本サービスは利用できなくなります。

## 第5条(登録データ)

1. 登録データは、利用組織が所有するGoogleアカウント上に保存され、利用組織が管理します。FSIFは登録データにアクセスせず、保存もしません。FSIFが利用組織から受け取るのは、第6条のアンケートの回答と団体単位の集計値、および本サービスの提供に必要な利用組織の情報だけです。
2. 利用組織内での登録データの閲覧範囲、利用目的、保存期間などは、利用組織が定めます。利用者は、利用組織の定めに従って登録データを扱うものとします。
3. 利用者は、本サービスの利用に必要な範囲を超えて、健康状態、家庭の事情その他特に配慮を要する情報を入力しないよう注意してください。
4. 本サービスにおける情報の取扱いは、別途定めるプライバシーポリシーによります。

## 第6条(アンケートとデータ提供)

1. アンケートへの回答とデータ提供は、利用組織が団体として行います。アンケートは、団体として1件の回答をお願いするもので、1回10分以内で終わる内容とします。
2. データ提供は団体単位の集計値に限ります。利用者個人を特定できる形のデータは含みません。
3. 利用組織がプランに応じて求められるアンケートに回答しない場合、利用契約に基づき、その利用組織の本サービスが機能停止になることがあります。機能停止の前には、本サービス上での表示その他の方法でお知らせします。
4. 機能停止中も登録データは消えず、閲覧と書き出しはできます。利用組織の回答が確認でき次第、すぐに再開します。

## 第7条(禁止事項)

利用者は、次の行為をしてはなりません。

1. 法令または公序良俗に違反する行為
2. 他人になりすます行為、他人のアカウントを使用する行為
3. 本サービスの閲覧権限の制御を回避し、閲覧を認められていない情報を取得しようとする行為
4. 本サービスを通じて知った他の利用者の情報を、利用組織の活動以外の目的で使用し、または第三者に公開する行為
5. FSIFが運用する本サービスの提供環境に対する不正アクセス、過度な負荷、その他本サービスの運営を妨げる行為
6. 他の利用者への嫌がらせ、差別、誹謗中傷その他の迷惑行為
7. その他、FSIFまたは利用組織が不適切と合理的に判断する行為

## 第8条(推薦・分析機能)

本サービスが示す担当候補の推薦、スキルの集計、リスクの表示などは、判断の参考となる補助的な情報です。FSIFはその正確性や適合性を保証しません。個人の評価や処遇に関わる判断は、人が確認したうえで行ってください。

## 第9条(本サービスの変更・停止・終了)

1. FSIFは、保守、障害への対応、セキュリティの確保その他必要がある場合、本サービスの内容を変更し、または一時的に停止することがあります。
2. 利用契約の終了、利用組織による規約違反その他利用契約で定める場合、FSIFはその利用組織への本サービスを提供停止にすることがあります。提供停止の14日前までに、本サービス上での表示その他の方法でお知らせします。ただし、緊急の場合は、当日のお知らせで提供停止にすることがあります。
3. 提供停止中は、その利用組織の利用者は本サービスを利用できません。この場合も、登録データは利用組織のGoogleアカウント上のスプレッドシートに残ります。
4. 本サービスは、FSIFが運用する仕組み(以下「レジストリ」)で、利用組織の機能停止・提供停止の状態を確かめます。レジストリに状態を確かめられない場合も、利用者は本サービスを使い続けることができます。

FSIFは、必要に応じて本規約を変更することがあります。重要な変更を行う場合は、効力が生じる日までに、本サービス上での表示その他の方法でお知らせします。変更後に本サービスを利用した場合、変更後の本規約に同意したものとみなします。
